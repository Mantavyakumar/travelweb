# GO QUEST — Travel Website 🌍✈️

Welcome to **GO QUEST**, a travel website designed to help users explore destinations, plan trips, and manage personalized travel itineraries with a clean and user-friendly interface.

🌐 **Live Website:**  
http://3.109.123.238/

---

## 🚀 About The Project

GO QUEST is a full-stack web application built using Django that allows users to register, log in, and plan their travel journeys. The platform includes a personalized itinerary planner where users can organize their trips and manage travel details securely using a database-backed system.

This project focuses on backend development, user authentication, form handling, and database integration along with a responsive frontend.

---

## 🧠 Features

- 🔐 User Authentication (Sign Up / Login / Logout)  
- 🗂️ Secure user data storage using **SQLite Database**  
- 📝 Forms built using **Django Forms**  
- 🧭 Personalized **Itinerary Planner**  
- 🌍 Explore travel destinations  
- 📱 Responsive and clean UI  
- ⚡ Fast and smooth navigation  

---

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Django (Python)  
- **Forms:** Django Forms  
- **Database:** SQLite  
- **Hosting:** AWS EC2

## 📦 How To Run Locally

Follow these steps to run the project on your system:

### 1️⃣ Clone the repository
```bash
git clone https://github.com/Mantavyakumar/travelweb.git
2️⃣ Go into the project folder
cd travelweb
3️⃣ Create a virtual environment
python -m venv venv
4️⃣ Activate the environment
Windows:

venv\Scripts\activate
Mac/Linux:

source venv/bin/activate
5️⃣ Install dependencies
pip install -r requirements.txt
6️⃣ Run migrations
python manage.py migrate
7️⃣ Start the server
python manage.py runserver
Now open your browser and visit:
👉 http://127.0.0.1:8000/
